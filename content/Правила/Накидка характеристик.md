Кидайте 3к6 по порядку для каждой характеристики и записывайте (карандашом) результат. А также совершите бросок к8, чтобы узнать ваше значение удачи.
По следующим характеристикам:
- Сила (СИЛ)
+/- модификатор к урону 
+/- модификатор к максимуму переносимого веса (при 0 - 10 предмето)

- Интеллект (ИНТ)
+/- модификатор к кол-во известных языков
+/- модификатор к скорости обучения

- Ловкость (ЛОВ)
+/- модификатор к попаданию
+/- модификатор к КБ

- Мудрость (МДР)
+/- модификатор к спасброскам
+/- модификатор к инициативе

- Телосложение (ТЕЛ)
+/- модификатор к броскам хитов
+/- модификатор к лимиту истощений перед смертельным истощением
+/- модификатор к хитам при лечение

- Харизма (ХАР)
+/- модификатор к кол-во наемников (при 0 - 4 максимум)
+/- модификатор к лояльности наемников

Каждому значению характеристики соответствует значение модификатора:

| 3к6   | Модификатор |
| ----- | ----------- |
| 3-    | -3          |
| 4-5   | -2          |
| 6-8   | -1          |
| 9-12  | 0           |
| 13-15 | +1          |
| 16-17 | +2          |
| 18    | +3          |
Вы можете поменять местами 2 характеристики на выбор
Вы можете пожертвовать 2 пунктами любой характеристики, чтобы увеличить другую на 1 пункт (так можно сделать 3 раза)

 Удача - это характеристика, выражающая удачливость персонажа.
- Удача выражена в очках, которые можно использовать в любой момент
- Удачу нельзя восстановит не магическими методами

Удача может быть потрачена на:
- Добавление +/- 1 к любому броску персонажа или броску, совершенному против персонажа
- Добавление Благо/Вреда к любому броску к20 для своего персонажа или для броска, совершенного против персонажа

- Персонаж начинает с к8 очками удачи
- Каждый новый уровень персонаж получает дополнительно к8 очков удачи

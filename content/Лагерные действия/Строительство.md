- Строительство требует лагерного действия, для более сложных потсроек может потребоваться несколько действий

- Строительство в данном случае предполагает возведение простых сооружений
- Например:
- Шалаш для сна
- Баррикады для защиты лагеря
- Наблюдательная вышка на дереве
- Ловушка для зверей
- Ловушка для людей
- Маленькая землянка
- Тайник

- Список не исчерпывающий и может быть дополнен любыми сооружениями, предложенными игроками
